While working on the payroll reporting app, I learned how to combine data processing with a user-friendly interface by allowing users to upload payroll exports, filter results by department and date, and review key information such as total hours, gross pay, monthly pay, and missed weeks. One challenge was organizing the code so that data cleaning and analysis remained separate from the Streamlit interface. I learned that the payroll package should handle data processing and calculations, while the Streamlit page should focus on displaying results and responding to user selections. Keeping these responsibilities separate made the application easier to understand and maintain. Moving forward, I want to practice handling missing or incorrectly formatted payroll data and displaying clear error messages when users upload invalid files. This project strengthened my understanding of interactive data applications and showed me how thoughtful filtering, accurate calculations, and useful feedback can make reports more reliable and accessible.
